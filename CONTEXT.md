# Verb Reference

A learner's reference for the forms of verbs in a target language and their grammatical glosses in the learner's user language.

## Language

**Target language**:
The language whose verbs the learner is studying. The initial target language is Spanish.

**User language**:
The single language used for both the interface and translation glosses. The initial user language is English.
_Avoid_: UI language or translation language as independently selectable preferences

**Available user language**:
A user language with complete interface text, grammatical glosses, and explanatory text for a particular target-language build.

**Target-language build**:
A separate edition of the app for one target language, with that language's verb inventory, grammatical categories, subject/address systems, regional choices, and presets.

**Subject label**:
A target-language pronoun or other subject designation associated with a verb form. Any learner-facing clarification, such as formality, is expressed in the user language.

**Grammatical heading**:
A user-language name for a grammatical category in the target language, such as English “Present indicative” for Spanish forms.

**Verb list**:
The collection of verbs available for selection in a target language, ordered by frequency. It aims for broad coverage and includes only verbs with frequency data.

**Spanish regional profile**:
The learner's choice of European or Latin American Spanish, determining the displayed address and plural forms.

**Verb frequency**:
The count assigned by the selected corpus to a verb lemma across its inflected uses. The same frequency ordering applies to both Spanish regional profiles; counts reflect the corpus's annotation.

**Pronominal entry**:
A selectable verb whose infinitive includes `se`, such as `arrepentirse`, and which has its own recorded corpus lemma count. A base verb's count does not establish a separate pronominal entry's frequency.

**Verb form**:
A form of a selected verb associated with its grammatical properties. The exact inventory of properties and forms depends on the target language.

**Grammatical gloss**:
A concise rendering of a verb form in the user language, including alternatives where needed to express its grammatical meanings.
_Avoid_: Exact translation

**Tense preset**:
A predefined selection of tenses used to filter the displayed verb forms. The default preset presents common learner tenses.
